01 — AI

会换表情的 AI 伙伴

每个智能体都有独立的人设、立绘与记忆。回复会被识别成情绪，气泡与立绘随之变化。

  • 九种情绪：平静、开心、惊讶、疑惑、困倦、傲娇、害羞、难过、生气
  • 每种情绪可放三张立绘，切换时随机取一张并交叉淡入
  • API Key 由你自己填写，只保存在本机

FAQ

常见问题

收费吗？有广告吗？

完全免费。没有广告、没有会员墙，也不收集使用数据。

AI 需要自己准备什么？

需要自己申请一个 API Key（推荐 DeepSeek，几块钱可用很久），在 设置 → 人设设置 → 接口 里填写。软件不内置 Key。不填时 AI 以本地演示模式回复。

数据存在哪里？

书签、便签、AI 对话、壁纸与立绘都保存在本机 %APPDATA%\my-browser。删除程序目录不影响这些数据。

怎么更新？

设置 → 关于 → 检查更新，有新版本会自动下载并替换，重启后生效。也可以直接下载新版解压覆盖。
