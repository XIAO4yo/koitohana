FAQ

常见问题

要钱吗？会不会有广告？+
完全免费，没有广告、没有会员墙、不收集使用数据。
AI 功能需要我自己准备什么？+
需要你自己在 DeepSeek 等平台申请一个 API Key（几块钱能用很久），填进设置里即可。软件本身不内置 Key，也不会把你的额度用掉。
我的数据存在哪里？+
全部保存在本机 %APPDATA%\\my-browser 目录里：书签、便签、AI 对话、壁纸、立绘。不上传任何服务器。
以后怎么更新？+
设置 → 关于 →「检查更新」，有新版会直接下载并自动替换重启，不用手动重新装。
会出 macOS 版本吗？+
目前只支持 Windows。跨平台移植工作量比较大，暂时没有计划。
